# MarigeApp - 备婚助手小程序

> 🎉 专为备婚情侣打造的一站式待办管理、日程规划和婚礼筹备工具

## 📱 功能特点

### 💒 核心功能
- **首页仪表盘** - 婚礼倒计时、筹备进度、今日待办一览无余
- **待办管理** - 10大分类，支持优先级、截止日期、子任务
- **日历视图** - 月视图直观展示待办和时间节点
- **婚礼倒计时** - 精确到秒的倒计时，仪式感满满
- **预算管理** - 总预算控制，分类支出统计
- **供应商管理** - 婚庆、酒店、摄影等供应商信息一网打尽
- **宾客管理** - 宾客名单、出席状态、座位安排
- **清单模板** - 14个时间段的完整备婚清单

### 🎨 设计亮点
- 浪漫玫瑰金配色，温馨优雅
- 卡片式布局，清晰明了
- 流畅动画，舒适体验

## 🚀 快速开始

### 1. 下载项目
```bash
git clone https://github.com/lkn1004/MarigeApp.git
```

### 2. 打开项目
1. 下载并安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 打开开发者工具，选择"导入项目"
3. 选择 `MarigeApp` 文件夹
4. 编译运行

### 3. 开始使用
1. 首次打开设置婚礼日期和新人信息
2. 从清单模板中选择合适的待办清单
3. 开始规划完美婚礼！

## 🛠️ 技术栈

- **框架**：微信小程序原生框架

## 💡 使用建议

### 筹备时间规划
- **12个月前**：确定婚礼日期、预算、婚宴场地
- **6-8个月前**：确定婚庆策划、拍摄婚纱照
- **3-4个月前**：发送请柬、确定菜单
- **1个月前**：最终确认、婚礼彩排
- **婚礼当天**：享受人生最重要的时刻

### 预算分配建议
- 婚宴场地：30%
- 婚庆策划：15%
- 婚纱摄影：8%
- 婚纱礼服：8%
- 珠宝首饰：10%
- 其他杂项：29%
